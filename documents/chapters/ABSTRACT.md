# Abstract

This research presents the design, development, and evaluation of a low-cost, offline voice assistant prototype for hotel room service operations, targeting small to mid-sized hotels in Sri Lanka. The system addresses a practical gap in hospitality technology for developing economies: existing voice assistant solutions depend on cloud infrastructure, raise privacy concerns, and require reliable internet connectivity that many properties cannot guarantee.

The prototype runs entirely on a commodity Android tablet in the $50–$150 price range. All voice processing happens on-device using Vosk for speech recognition and a fine-tuned MobileBERT intent classifier exported as a TFLite model. A hybrid natural language understanding pipeline combines rule-based keyword matching with neural model inference to handle 18 hotel service intent categories covering common room service operations. A FastAPI backend with SQLite persistence and WebSocket communication manages the full request lifecycle, from guest voice input through to real-time staff notification and service tracking — all within a local hotel network, with no external data transmission.

Evaluation addressed three dimensions of viability. For NLU accuracy, a three-variant training experiment demonstrated that noise-aware training on paired clean and Vosk-transcribed data closes the accuracy gap introduced by real speech recognition: the baseline model dropped from 98.07% on clean text to 89.34% on Vosk output, while the noise-aware model recovered to 99.06% on the same Vosk-transcribed input. For speech recognition, the Vosk pipeline achieved an overall word error rate of 11.43% on hotel-domain utterances. For system performance, end-to-end latency reached a P95 of 2,827ms, within the 5-second target set for practical usability.

The results confirm that a fully offline voice assistant prototype, built on commodity Android hardware, achieves sufficient technical accuracy and performance to be a viable alternative to traditional room service communication in Sri Lankan hotels.
